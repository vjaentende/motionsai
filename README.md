# FORM/FUNCTION®

Experiencia web 3D interactiva para un estudio de diseño gráfico independiente.
La portada funciona como un playground WebGL: permite rotar, ampliar, seleccionar
esculturas, cambiar la paleta y controlar la energía de la animación.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run build
npm run lint
npm run test:e2e
```

Construido con React, TypeScript, Three.js y React Three Fiber.
