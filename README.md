# Twisty

Workspace SaaS para freelancers inspirado en la referencia visual proporcionada.
Incluye seguimiento de ingresos, proyectos, contactos, propuestas, mensajería y
cartera.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

Los proyectos, conexiones, métricas y estado de suscripción se conservan en
`localStorage`, por lo que la demo funciona sin un backend.
