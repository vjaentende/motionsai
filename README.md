# GPT-5.6 SOL — Launch Film

Pieza conceptual de lanzamiento creada con Remotion: 37 segundos, 1920×1080,
30 fps y banda sonora procedural original.

## Uso

```bash
npm install
python3 generate_score.py
npm start
```

Render final:

```bash
npm run render
```

El vídeo se guarda en `out/gpt-sol-launch.mp4`. La composición principal,
`GPTSolLaunch`, se puede personalizar desde `src/Root.tsx`.

> Este proyecto es una pieza conceptual y no representa un anuncio oficial ni
> especificaciones verificadas de OpenAI.
