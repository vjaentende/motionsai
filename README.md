# NYC // 2026

Montaje vertical de Nueva York creado con FFmpeg: 1080×1920, cortes rápidos,
flashes, barridos, tipografía cinética, color intenso y audio electrónico
original.

## Generar el vídeo

```bash
python3 make_nyc_video.py
```

El script descarga automáticamente las versiones HD del metraje desde
Wikimedia Commons y genera `output/nyc_dopamine_2026.mp4`.
